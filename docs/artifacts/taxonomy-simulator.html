Coarse is not wrong. Emerge fails only when it merges distinct concepts. A cluster that sits one level too high is a valid higher node — which is why scoring emerge against someone else's reference taxonomy punishes correct answers. What the two simulations together show

Map is a cheaper version of reading everything, and that is the point: same column, same accuracy, a fifth of the calls. The gate only decides which clauses get read.

Emerge is not. Reading each document in turn yields N independent labels, never a taxonomy — structure lives in the relationships between documents, which a per-document pass never sees.

The obvious objection is a long-context model: put the whole corpus in one prompt. Two things cut against each other here, and neither wins outright. Clustering compares exhaustively but shallowly — 240 clauses means all 28,680 similarities are actually computed, nothing skipped, so a category nobody expected still surfaces. But each comparison is a cosine score from a 137M-parameter embedder, which blurs distinctions a frontier model finds trivial: negation is the classic failure, with “shall indemnify” and “shall not indemnify” landing close together. A frontier model compares deeply but selectively — genuine comprehension per pair, no guarantee it surveyed everything, and position bias over long contexts.

So this is not “clustering beats the model”. The false merges in the simulation above, and the 41–50% leaf purity measured on LEDGAR, are the shallow-comparison ceiling showing through. That is precisely why the gate exists: the cheap pass organises everything and flags where it is unsure, and the expensive model is spent there. The head-to-head against a long-context frontier model has not been run — treat the comparison as an open question, not a result.

The honest ceiling: at a 100% budget you are reading everything, and accuracy lands at 96.5% — the gated hybrid reaches 96.2% at a fifth of that. The paired bootstrap puts the gap at −0.2 points, 95% CI [−2.5, +2.0]: parity, not a win. Anyone claiming the shortcut beats exhaustive reading is over-reading the noise.
